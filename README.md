# نظام نوى للمشاريع والمستفيدين (v0.1)
- التشغيل: افتح `Nawa_System.html` بالنقر المزدوج (يعمل دون إنترنت؛ البيانات تُحفظ في المتصفح — خذ نسخة احتياطية JSON دوريًا).
- التطوير: `npm i` ثم `npm run dev` | البناء: `npm run build` | الاختبارات: `npm test` و `node test/ptt_lo.mjs` (يتطلب LibreOffice).
- core/: المحرك (aggregate: الحساب، validate: التحقق والتكامل، ptt-export: تعبئة قالب Annex 5 على مستوى XML، xlsx-export: STT/BTT).
- app/: الواجهة (RTL، هوية نوى).

## السحابة (المزامنة)
- الخادم (Node 22+، بلا اعتمادات): `PORT=8787 NAWA_DB=./nawa-data.sqlite node server/server.js` — يطبع رمز المدير مرة واحدة عند أول تشغيل، ويقدّم التطبيق نفسه على `/`.
- مستخدمون: `node server/cli.js add <اسم> <admin|meal|entry|coordinator> [مراكز]` | `list` | `disable <اسم>`.
- Docker: `npm run build` ثم `docker build -t nawa-sync .` ثم `docker run -p 8787:8787 -v nawa-data:/data nawa-sync`.
- ضعه خلف HTTPS (Caddy/nginx) قبل أي استخدام عبر الإنترنت. النسخ الاحتياطي = نسخ ملف SQLite.
- المزامنة: تعمل دون إنترنت، تدمج على مستوى السجل (الأحدث يفوز)، الحذف بشواهد، التغييرات المعلّقة تُرسل عند عودة الاتصال.
- الاختبار: `node --no-warnings --test test/sync.test.js`.

## الأدوار والصلاحيات
- الأدوار: `admin` (مدير)، `meal`، `entry` (مدخل بيانات المكتب)، `coordinator` (منسق مركز، يرى ويكتب جلسات وردود مراكزه فقط).
- تُفرض على الخادم: الجلسات خارج المركز لا تصل الجهاز، والكتابة خارجه تُرفض وتُردّ نسخة الخادم، والحقول المخفية (الهاتف، نوع الإعاقة…) لا تصل وتبقى محفوظة عند تعديل السجل.
- المدير يضيف المستخدمين ويعدّل الصلاحيات من شاشة «المستخدمون والصلاحيات» (رمز الدخول يظهر مرة واحدة).
- الاختبار: `node --no-warnings --test test/perm.test.js`.

## الاستبيانات (KoBo)
- `core/forms.js`: 5 نماذج XLSForm تُنزَّل من شاشة «الاستبيانات»، تتحقق منها `test/forms.test.js` بـ pyxform.
- `core/outcomes.js`: استيراد ردود KoBo (XLSX) وحساب مؤشرات النتائج (نسبة تجاوز حدّ / نسبة التحسّن قبلي→بعدي) وكتابتها في Outcome indicators.

## المزامنة عبر مجلد OneDrive (بدون خادم)

1. ثبّت OneDrive على الجهاز وأنشئ مجلدًا مثل `NawaSync` بداخله مجلدات القنوات: `core` (البيانات الأساسية)، `pii` (الهاتف ونوع الإعاقة)، و`c-<معرّف المركز>` لكل مركز.
2. شارك كل مجلد فرعي عبر OneDrive مع من يحق له فقط (الصلاحيات = مشاركة OneDrive). الجهاز يزامن القنوات المتاحة له فقط.
3. في تبويب «السحابة» اختر «مجلد OneDrive» ثم «اختيار المجلد» (متصفح Edge/Chrome) ثم «مزامنة».
- كل جهاز يكتب ملفه الخاص `<deviceId>.json` فلا تتعارض الملفات؛ الدمج بآخر تعديل (ts).
- القيد: يعتمد على ساعة الجهاز، ويلزم عميل OneDrive المكتبي.

## تغطية أوراق قالب PTT (Annex 5)
| الورقة | المصدر |
|---|---|
| Output indicators / Beneficiaries Breakdown / Project Work plan | تلقائي من الجلسات والمستفيدين |
| Outcome indicators | تلقائي من ردود KoBo |
| Project Tracking Table | خطوط الأساس والمستهدفات يدويًا (تبويب «المستهدفات»)، والفعلي تلقائي، والمستفيدون المباشرون من محرك النظام |
| Poject Info. Sheet / Log frame / Indicator Profile / MEAL Calendar / Assumptions / Learning Management | شاشة «ملف PTT الكامل» |
| Overview Dashboard | معادلات القالب؛ المصروف من «معلومات المشروع» |
- أُصلح خطأ في القالب: صف 15 في جدول PTT كان يشير إلى خلية خاطئة.
- فحص التصدير: `node test/plan_lo.mjs` و `node test/ptt_lo.mjs` (إعادة حساب بـ LibreOffice).

## منشئ الاستبيانات
من «الاستبيانات (KoBo)» → «منشئ الاستبيانات»: أنشئ استبيانًا أو انسخ قالبًا جاهزًا، أضف أسئلة (مقياس، اختيار واحد/متعدد، نص، رقم، تاريخ، ملاحظة)، رتّبها، ثم نزّل XLSForm وارفعه في KoBo. أسئلة المقياس تُجمع في `score_total` لمؤشرات النتائج. تُحفظ النماذج في المشروع وتتزامن معه. (اختبار pyxform في test/forms.test.js)

## نسخة الرابط (Artifact)
`npx vite build && python3 tools/make-artifact.py` ينتج `out/artifact/index.html` للنشر كرابط ثابت يتحدّث عند كل نشر. في هذه النسخة: البيانات في متصفح المستخدم فقط، التنزيل عبر صلاحية downloads، ولا مزامنة سحابية (استخدم JSON للنقل).

## كشوفات الحضور (بديل Word) والإنجاز التشغيلي

- شاشة **كشوفات الحضور (إدخال)**: تسعة نماذج مطابقة للكشوف الورقية — دورة، تدريبات تربويين، تدريبات أهالي، نشاط، يوم مفتوح، رحلة، زيارة (زوار)، نشاط مشترك، ومقابلة توثيق تراث شفوي.
  ترويسة كل نوع بحقولها وفئاتها المسموحة؛ الأعداد (الإجمالي/ذكور/إناث/إعاقة/نوع الإعاقة) **تُحسب تلقائياً من القائمة** ولا تُكتب يدوياً.
- لا يُحفظ كشف فيه خطأ: حقول إلزامية، تواريخ خارج المشروع/مستقبلية/مكررة، وقت نهاية قبل البداية، عمر خارج الفئة المختارة، اسم أقل من 3 مقاطع، إعاقة بلا نوع، هاتف غير صالح، لقاء بلا حاضر، عدد لقاءات أكثر من الإجمالي. التنبيهات (مثل ازدواج حضور الشخص نفسه في الوقت نفسه) تطلب تأكيداً.
- الكشف = مصدر البيانات؛ تُولَّد منه جلسات STT تلقائياً فتبقى BTT/PTT/لوحة القيادة متسقة. تعديل الكشف أو حذفه يعدّل جلساته.
- الدورات متعددة اللقاءات: مصفوفة حضور (مشارك × لقاء) مع نسبة حضور كل مشارك ومدى استيفائه نسبة الحضور الإلزامية.
- **الإنجاز التشغيلي**: للأنشطة بلا حضور (تدقيق، صيانة، مشتريات، أرشفة…). كل سجل بتاريخ وكمية ومرجع إلزامي. تغذّي مؤشرات «عدد منجز»؛ أما «عدد الجلسات المنفَّذة» فتلقائي من STT. القالب بلا عمود إجمالي فتُكتب هذه المؤشرات في عمود الفئة الأولى مع تنبيه عند التصدير.
- **مشروع GIZ النموذجي** (زر «تحميل مشروع GIZ النموذجي»): بنية Final Logical Framework (4 أهداف محددة؛ الهدفان 3 و4 تحت النتيجة 3 في PTT: 3.1 التراث و3.2 الاستدامة) مع بيانات وهمية قابلة للحذف بالكامل.
- اختبارات: `node --test test/*.test.js` ثم `test/e2e_sheets.mjs` و`test/e2e_giz.mjs` (متصفح) و`SIM=giz node test/ptt_lo.mjs` (إعادة حساب LibreOffice).

## الواجهة: الخطوط واللغتان
- خط الواجهة **Tajawal** (النص) و**Cairo** (العناوين)، مضمَّنان داخل الملف (`@fontsource`) فيعملان دون إنترنت. الخطوط في `app/style.css` (`--f-body`, `--f-head`).
- خط التصدير يبقى **Sakkal Majalla** (`BRAND.font` في `core/xlsx-export.js`) ولا تمر طبقة التصدير على الخطوط أو اللغة (يحميه `test/font.test.js`).
- زر **English / العربية** في أعلى الصفحة يبدّل اللغة والاتجاه (RTL/LTR) ويحفظ الاختيار. الترجمة في `app/lang-en.txt` (سطر لكل عبارة: `عربي | English`) وتُطبَّق بـ `app/i18n.js` على نصوص الواجهة؛ ما لم يُترجَم يبقى بالعربية. بيانات المستخدم (أسماء المشاريع والأنشطة والمستفيدين) لا تُترجَم.
- اختبار: `node test/e2e_lang.mjs`.

## الهوية البصرية والوضع المظلم والتلميحات
- الزخارف الفلسطينية (نجمة التطريز ثمانية الرؤوس، غصن الزيتون، شبكة الكوفية، حد المثلثات بألوان العلم) تُولَّد بـ `python3 tools/make-patterns.py` إلى `app/patterns.css` كصور SVG مضمَّنة (تعمل دون إنترنت) بنسختين فاتحة ومظلمة.
- الوضع المظلم: زر الهلال/الشمس في الرأس؛ يتبع إعداد الجهاز أول مرة ثم يحفظ اختيارك. كل الألوان متغيرات في `app/style.css`.
- الملاحظات التوجيهية (`p.small` تحت العناوين) تتحول تلقائيًا إلى أيقونة ⓘ بجانب العنوان تظهر عند اقتراب المؤشر؛ وأيقونة 💡 في الرأس تجمع تلميحات الشاشة الحالية، وأيقونة 🔔 تعرض الأخطاء والتنبيهات (`app/ui-tools.js`).

## نسخ البطاقات
عند تمرير المؤشر على أي بطاقة (في كل شاشات البرنامج) تظهر أيقونتان فوقها: **نسخ كصورة** (PNG للحافظة، أو تنزيلها إن منع المتصفح) و**نسخ الملخص** (نص؛ الجداول والمخططات تُنسخ بفواصل أعمدة TAB فتُلصق في Excel كجدول). الكود في `app/copy-card.js`، واختباره `test/e2e_copy.mjs`.
